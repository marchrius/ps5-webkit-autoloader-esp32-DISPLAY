# Repository instructions

## Version control

- Use standard Git for all version-control operations in this project.
- Do not use GitButler or the `but` CLI, and do not create a `gitbutler/workspace` branch.
- Preserve unrelated local changes and generated files; commit only the requested work.
- Use commit messages in the form `type(scope): summary`.
- Do not push or open pull requests unless the user requests it.
